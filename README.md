# HAPPY BIRDDAY

Интерактивное одностраничное приглашение на «Бал перелётных птиц» с результатами «Жаворонок», «Голубь» и «Сова».

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка и проверка типов:

```bash
npm run build
```

## Где менять содержание

Основные тексты, вопросы, баллы, маршруты, погодные сценарии, товары, ссылки, адреса и контакты находятся в `src/data/content.ts`.

Временные элементы:

- все товарные изображения и ссылки AliExpress;
- ссылка на Oh My Wishes;
- крупная птичья сцена на обложке.

## Как сохраняются ответы

Каждый ответ сохраняется в `localStorage` под ключом `happy-birdday-response-v2`. Один и тот же `responseId` используется при смене маршрута и повторном прохождении теста.

Без endpoint сайт показывает деморежим: данные остаются только на устройстве.

## Подключение Google Sheets

1. Создать Google Sheet.
2. Открыть **Расширения → Apps Script**.
3. Скопировать содержимое `google-apps-script/Code.gs`.
4. В **Настройки проекта → Свойства скрипта** добавить `SPREADSHEET_ID` со значением ID таблицы из её URL.
5. Выбрать **Развернуть → Новое развертывание → Веб-приложение**.
6. Выполнять от своего имени; доступ — «Все».
7. Скопировать URL развертывания `/exec` в локальный `.env`:

```bash
VITE_GOOGLE_APPS_SCRIPT_URL=https://script.google.com/macros/s/DEPLOYMENT_ID/exec
```

После изменения `.env` перезапустить dev-сервер.

Скрипт обновляет строку по `responseId`, а не создаёт дубль. Для списка участников отфильтровать `excursionConfirmed = TRUE`; итоговое число — сумма `excursionPartySize`.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает проект с base `/happy-birdday/`. Перед публикацией:

1. Проверить имя репозитория и при необходимости заменить `VITE_BASE_PATH`.
2. Добавить repository secret `VITE_GOOGLE_APPS_SCRIPT_URL`.
3. Включить источник **GitHub Actions** в Settings → Pages.
